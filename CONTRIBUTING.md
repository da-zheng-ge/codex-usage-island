# Contributing

1. Create a focused branch.
2. Keep the runtime compatible with Windows PowerShell 5.1.
3. Do not add bundled Codex binaries, OpenAI brand assets, credentials, logs, or machine-specific paths.
4. Parse PowerShell files before submitting a change.
5. Describe visible behavior changes and include screenshots when UI behavior changes.
